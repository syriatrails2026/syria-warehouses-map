# تصميم موقع خريطة مخازن سوريا التفاعلية

**التاريخ:** 2026-09-07
**الحالة:** معتمد (Approved) — بانتظار مراجعة نهائية من المستخدم

## السياق والهدف

وزارة التجارة الداخلية السورية طلبت مساعدة في تسويق مشروع قائم (1,400 مخزن موزّعة على كل محافظات سوريا) بهدف إقناع مستثمر بالتوقيع والاستثمار في المشروع. المطلوب هو **موقع عرض تفاعلي (marketing/demo site)** شبه رسمي، احترافي، يعرض توزّع المخازن جغرافياً عبر خريطة سوريا التفاعلية، مقسّمة هرمياً (محافظة ← منطقة ← ناحية)، مع إحصائيات عامة وبطاقة تفاصيل لكل مخزن.

## نطاق هذه المرحلة

**داخل النطاق:**
- الموقع العام (Public-facing site) بالكامل: الهيدر، شريط الإحصائيات، القائمة الجانبية، الخريطة التفاعلية الهرمية، بطاقة تفاصيل المخزن.
- بيانات وهمية (Mock data) لـ1,400 مخزن، موزّعة بشكل واقعي ضمن حدود الوحدات الإدارية الفعلية (وليس عشوائياً فوق كامل الخريطة).
- بنية بيانات مُصمَّمة بحيث يسهل مستقبلاً استبدالها ببيانات حقيقية قادمة من لوحة تحكم ورفع ملفات Excel.

**خارج النطاق (مرحلة مستقبلية منفصلة):**
- لوحة التحكم الإدارية (Control Panel) لرفع بيانات المخازن من ملف Excel.
- أي خادم/API حقيقي، قاعدة بيانات، أو نظام صلاحيات/تسجيل دخول.
- دعم لغات إضافية (الموقع عربي فقط RTL في هذه المرحلة).

## المتطلبات المؤكدة

1. **البيانات الجغرافية:** ملفات GeoJSON متوفرة فعلياً على 3 مستويات: محافظة ← منطقة ← ناحية (يزوّدها المستخدم).
2. **عرض المخازن:** عند الوصول لأصغر مستوى إداري (الناحية)، تظهر المخازن كنقاط (Pins) فعلية فوق الخريطة ضمن حدود تلك الناحية؛ الضغط على نقطة يفتح بطاقة تفاصيل المخزن مباشرة.
3. **بطاقة المخزن:** تعرض اسم المخزن، مساحته، ورابط للانتقال إلى موقعه على خرائط جوجل (مبني من الإحداثيات).
4. **التنقل الهرمي:** الدخول لمحافظة يُظهر عدد المخازن مكتوباً عليها، ثم تقسيمها لمناطق (كل منطقة بعدد مخازنها)، ثم دخول منطقة يُظهر نواحيها (كل ناحية بعدد مخازنها).
5. **اللغة:** عربي فقط، اتجاه RTL بالكامل.
6. **الهوية البصرية:** مستوحاة من ألوان العلم السوري الجديد (أخضر، أبيض/كريمي، أسود، مع تفادي استخدام الأحمر بشكل مباشر) — تم اعتماد لوحة "أخضر داكن + ذهبي/رملي" (انظر قسم الهوية البصرية).
7. **الأسلوب العام:** شبه رسمي، غير معقّد، سلس بالتنقل، احترافي جداً، نظيف بصرياً وتقنياً.
8. **اسم المشروع:** غير محدد بعد — يُستخدم اسم عام/وصفي مؤقت، قابل للتغيير من مكان واحد (ثابت إعدادات) دون التأثير على الكود.

## القرارات التقنية

### أسلوب الخريطة: Infographic مخصّصة (وليس خريطة واقعية بـ Tiles)

تمت مقارنة خيارين بصرياً مع المستخدم:
- **خريطة واقعية** (طبقات Tiles من OpenStreetMap/Google) مع تظليل حدود سوريا فوقها — مألوفة لكنها تُظهر تفاصيل شوارع ودول الجوار لا تخدم الهوية البصرية المؤسسية.
- **خريطة مخصّصة (Infographic)** — تعرض فقط شكل سوريا ومحافظاتها بألوان الهوية، بخلفية نظيفة، بدون أي عناصر خارجية.

**تم اعتماد الخيار الثاني.** هذا يعطي تحكماً كاملاً بالألوان والمظهر، ويناسب طابع "شبه رسمي/مؤسسي" المطلوب.

### محرك الرسم: D3.js

بما أن الخريطة مخصّصة (لا تعتمد على tiles)، فمكتبات الخرائط التقليدية (Leaflet, MapLibre) غير مناسبة لأنها مبنية أصلاً حول نموذج "خريطة عالمية ببلاطات". **D3.js** (`d3-geo` + `d3-zoom`) هو المعيار القياسي لرسم خرائط GeoJSON مخصّصة (choropleth/infographic)، ويوفر:
- تحكماً كاملاً بالألوان والتفاعل لكل معلم جغرافي (governorate/district/subdistrict) على حدة.
- انتقالات سلسة (smooth transitions) بين مستويات التنقل الهرمي.
- تكبير/تصغير وتنقل (zoom/pan) سلس عبر `d3-zoom`.

تم عرض البدائل (Leaflet بدون tiles، رسم Canvas/SVG يدوي بالكامل) على المستخدم مع التوصية بـD3.js، وتمت الموافقة.

### التقنية العامة: React + Vite (SPA ثابت)

موقع صفحة واحدة (Single Page Application)، بدون خادم خلفي — بيانات ثابتة يتم توليدها وقت البناء/التطوير. سهل النشر كموقع ثابت (Vercel/Netlify/أي استضافة ثابتة).

### طبقة البيانات: قابلة للاستبدال مستقبلاً

- `src/data/geo/` — ملفات GeoJSON الثلاثة (محافظات، مناطق، نواحي).
- سكربت توليد بيانات وهمية (`scripts/generate-fake-warehouses.mjs`) يستخدم مكتبات `@turf/*` (تحديداً نقطة عشوائية داخل مضلّع — `@turf/random` مع التحقق عبر `@turf/boolean-point-in-polygon`) لتوزيع 1,400 مخزن **داخل حدود النواحي الفعلية**، وليس عشوائياً فوق صندوق إحداثيات الدولة بالكامل. الناتج: `src/data/warehouses.generated.json`.
- واجهة بيانات مجرّدة `src/data/warehouseSource.ts` بتوقيعات مثل:
  ```ts
  getWarehouses(): Promise<Warehouse[]>
  getGovernorateStats(): Promise<GovernorateStats[]>
  ```
  كل مكوّنات الواجهة تستهلك هذه الواجهة فقط، ولا تتعامل مباشرة مع ملف JSON. لاحقاً، عند بناء لوحة التحكم وربط API حقيقي، **يُستبدل تطبيق هذه الواجهة فقط** (من "قراءة JSON محلي" إلى "نداء HTTP")، دون أي تعديل على مكوّنات العرض. هذا يحقق متطلب "سهولة الربط المستقبلي بلوحة تحكم وAPI حقيقي".

### التنقل: مزامن مع رابط الصفحة (URL State)

حالة الاختيار الحالية (محافظة/منطقة/ناحية) تُعكس في query params بالرابط (مثال: `?gov=damascus&region=...`). هذا يحقق:
- عمل زر "رجوع" بالمتصفح بشكل طبيعي (يرجع مستوى للخلف في الخريطة).
- إمكانية مشاركة رابط مباشر لمستوى تنقّل معيّن.

## المكوّنات (Components)

| المكوّن | الوصف |
|---|---|
| `Header` | ثابت أعلى الصفحة. اسم/شعار المشروع (عام، قابل للتغيير من ثابت واحد) + رابط اختياري "عن المشروع". بدون قوائم معقّدة. |
| `StatsToolbar` | أسفل الهيدر مباشرة. 5 بطاقات إحصائية: إجمالي عدد المخازن (1,400) · إجمالي المساحة (م²) · متوسط مساحة المخزن (م²) · أكبر محافظة من حيث عدد المخازن · بطاقة ديناميكية تعرض عدد المخازن ضمن النطاق المعروض حالياً (تتحدّث تلقائياً أثناء التنقل). |
| `Sidebar` | يمين الصفحة (بداية التخطيط بـRTL). قائمة ثابتة بالمحافظات الـ14 مع عدد مخازن كل منها + مربع بحث (بالاسم/المحافظة/المنطقة/الناحية). الضغط على محافظة بالقائمة يزامن الخريطة معها ويدخلها. |
| `Breadcrumb` | فوق الخريطة: سوريا ← محافظة ← منطقة ← ناحية. كل مستوى قابل للنقر للرجوع إليه مباشرة. |
| `MapCanvas` | الخريطة التفاعلية (D3 SVG) بـ4 حالات عرض متسلسلة: **وطنية** (14 محافظة ملوّنة حسب كثافة المخازن + رقم بكل محافظة) ← **محافظة** (مناطقها، كل منطقة برقمها) ← **منطقة** (نواحيها، كل ناحية برقمها) ← **ناحية** (نقاط/Pins فردية بإحداثيات المخازن الحقيقية). |
| `WarehouseCard` | بطاقة عائمة تظهر عند الضغط على نقطة مخزن: اسم المخزن، المساحة، زر "فتح في خرائط جوجل" (رابط `https://www.google.com/maps?q={lat},{lng}` مبني من الإحداثيات). |

## الهوية البصرية

**الألوان** (مستوحاة من العلم السوري الجديد، بلوحة "أخضر داكن + ذهبي/رملي" المعتمدة):

| الاستخدام | اللون |
|---|---|
| أخضر أساسي داكن (Header, نصوص مهمة) | `#0f2a1c` |
| أخضر متوسط (تمييز، حالة نشطة) | `#1d4a30` |
| أخضر فاتح (تفاعلات، hover) | `#2f6b46` |
| ذهبي/رملي (تمييز، أرقام بارزة، لمسة "استثمارية") | `#c8a84b` |
| رملي فاتح (خلفيات ثانوية) | `#dcc27a` |
| خلفية كريمية دافئة | `#f7f5ef` / `#faf9f6` |
| نص أساسي (على خلفية فاتحة) | `#1f2d24` |

**تم تفادي استخدام الأحمر كلون أساسي** (رغم وجوده بنجوم العلم) تجنّباً لأي إيحاء سياسي مباشر في سياق موقع استثماري، بناءً على مقارنة بصرية مع المستخدم واختياره الصريح.

**الخط:** خط عربي احترافي نظيف عبر Google Fonts — **Tajawal** أو **IBM Plex Sans Arabic** (شائعان بمواقع حكومية/مؤسسية رسمية بالمنطقة، دعم ممتاز للعربية بأوزان متعددة).

**الاتجاه والتخطيط:** `dir="rtl"` بالكامل على مستوى الصفحة. تصميم متجاوب (Responsive) — على الشاشات الصغيرة يتحول الشريط الجانبي لقائمة سفلية قابلة للسحب (bottom sheet)، وبطاقات الإحصائيات تصبح شريطاً أفقياً قابلاً للتمرير.

## حالات الحافة (Edge Cases)

- وحدة إدارية (محافظة/منطقة/ناحية) بدون أي مخازن: تظهر على الخريطة بلون محايد مع "0 مخازن" مكتوبة عليها — **لا تُخفى**.
- فشل تحميل أحد ملفات GeoJSON: رسالة خطأ واضحة بدل شاشة فارغة أو تعطّل الموقع.
- بحث بدون نتائج بالقائمة الجانبية: حالة "لا توجد نتائج" واضحة.
- كثافة نقاط عالية داخل ناحية واحدة: بما أن متوسط توزيع 1,400 مخزن على ~270 ناحية سورية يعطي ~5 مخازن/ناحية بالمتوسط، **لا حاجة لتجميع (clustering) النقاط** في هذه المرحلة — يُعاد تقييم الأمر لاحقاً إذا تبيّن تكدّس حقيقي في بيانات فعلية.

## الاختبارات

نطاق عملي (YAGNI) بدون إثقال المشروع:
- اختبارات وحدة (Vitest) لسكربت توليد البيانات الوهمية: كل نقطة تقع فعلياً داخل حدود الناحية المخصّصة لها، ومجموع المخازن المولّدة = 1,400 بالضبط.
- اختبارات وحدة لمنطق حالة التنقل الهرمي (اختيار محافظة/منطقة/ناحية، والرجوع للخلف).
- بدون اختبارات UI شاملة (snapshot/e2e) في هذه المرحلة — الموقع صفحة عرض واحدة محدودة التعقيد.
