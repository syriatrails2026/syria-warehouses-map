# خريطة مخازن سوريا التفاعلية

موقع عرض تفاعلي لصالح وزارة التجارة الداخلية السورية، يعرض توزّع 1,400 مخزن على خريطة سوريا بشكل هرمي (محافظة ← منطقة ← ناحية).

**المستودع على GitHub:** https://github.com/syriatrails2026/syria-warehouses-map

للتفاصيل الكاملة (النطاق، التقنيات، الهوية البصرية، حالة التنفيذ)، راجع [CLAUDE.md](CLAUDE.md).

## التشغيل محلياً

```bash
npm install
npm run dev
```
